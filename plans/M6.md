## Goal

An image with real `@actor` structs runs on the wrela VMM: `@test(runtime)`
fns (sync or `async`) are the root turns; they call actor methods through
image-minted handles, `await` replies, `send` one-way messages, open
`with group(...)` scopes with capacities and deadlines, and observe
cancellation only at awaits and checkpoints. Turn-per-actor
non-reentrancy, FIFO admission, bounded mailboxes, and deterministic
teardown are all pinned by transcript goldens booted on HVF. Replay comes
alive as an enumerable choice sequence (on one core it has exactly one
admissible schedule — the representation still must carry choices, not
just a log).

## The honest scope line (decide once)

M6 is actors-on-core-0, not the whole async chapter. IN: `@actor` structs
with `async fn`/`fn` public methods; `Actor[T]` handle calls composing
`CallError[E]` per 02 §9.4; `await`; `send` (statement and
must-consume-Result forms); `with group(capacity=..., deadline=...)`,
`g.start`, `g.join_all`, implicit request-groups; ambient lineage;
deadline inheritance/narrowing; cancellation at awaits/checkpoints;
`defer`-based cleanup in reverse order; mailbox bounds (declared);
checkpoint emission + vector delivery + park/wake with the VMM; `now()`/
`ms()` as compiler-recognized intrinsics backing deadlines (the doc's own
§9.5 vocabulary; clock MMIO already exists). OUT (each fails closed,
named): pools/`own` in messages and actor-scoped `pool` runtime (M7 with
devices), receipts/drivers/ISRs (M7), `race` (sealed contract — after
group teardown is proven), `@detached`, `@task` installed roots (the
runtime-test root substitutes at M6), service slots (stdlib), placement
inference and `core=` ≠ 0 (M8), mailbox capacity *derivation* (declared
`mailbox=` is the bound; derivation is later), `must_service_within`,
restart/supervision *runtime* (the graph is checked since M4; restart
mechanics are M7+ — an actor abandon at M6 is image-fatal with a
diagnosable transcript line, recorded honestly).

## Shape decisions (frozen by goldens — decide once)

1. **Execution surface stays `@test(runtime)`** — now sync or `async`
   (02 §12.2's own words). The generated harness starts the image
   (actors constructed in dependency order from the M4 graph, mailboxes
   opened atomically per 04 §9), then runs each test as a root turn on
   the core-0 event loop. Tests still run strictly sequentially — one
   root turn at a time; a test's awaits interleave *actor* turns, which
   is the whole point.
2. **FlowWir materializes** (04 §8's named layer; M5 fused it away for
   sync code): async fns lower AOT to state machines in statically
   reserved frame slots (04 §2) — FlowWir is the typed, suspension-
   explicit form between the typed tree and mwir: states, awaits as
   suspension edges, lineage/deadline plumbing explicit, cleanup edges
   explicit. `wrela dump --stage=flowwir` before features, golden-
   covered. Sync fns keep the M5 path unchanged (existing goldens must
   not move).
3. **One event loop, one core, priority bands** per 04 §2: bands exist
   in the representation (device/normal/background) but only "normal"
   is populated at M6; FIFO per mailbox by admission order; scheduling
   key = FIFO head's (priority, effective deadline); ties by the
   deterministic round-robin cursor. The loop, mailboxes, frames, and
   admission slots are all statically laid out (no allocation): every
   actor's mailbox capacity, frame-slot arena (one slot per declared
   in-flight activation), and the scheduler's own tables are sized at
   build time into the data section — the report grows the accounting
   (sizes only, facts).
4. **Non-reentrancy is structural**: one turn owns the actor until
   return/error/abandon; an await parks the turn, marks the actor
   busy-suspended, admits nothing. Pinned by the flagship golden: actor
   A awaits B while a second message to A sits queued; the transcript
   proves the second turn starts only after the first completes
   (`actors.turns.non-reentrant`'s flip witness).
5. **`send` proof discipline** (02 §9.4): a bare `send` statement is
   legal ONLY where admission provably cannot fail; otherwise the
   `Result[unit, Rejected[...]]` must be consumed. M6 ships the
   dumbest sound proof: admission cannot fail iff the target mailbox's
   declared capacity ≥ the whole-image count of static send/call sites
   targeting it AND every such site sits outside any loop and outside
   any `g.start` child (so each executes at most once per root turn)
   AND root turns are serial (decision 1 guarantees this at M6). If
   that condition doesn't hold, the bare statement is a named
   `error[actor]` (new fixed category, added deliberately) telling the
   author to consume the result. If the executed goldens show this
   proof too weak to ever fire, the flip still stands on both sides
   (accept golden where proven, err golden where not) — never widen
   the proof without the analysis staying obviously sound. Record the
   shipped condition verbatim in the ledger clause.
6. **Checkpoints**: codegen emits a checkpoint at every loop back-edge
   and every turn boundary (await resume points are checkpoints by
   construction). No bound proving, no elision — a checkpoint is a
   short fixed sequence (load pending word, test, branch to the
   scheduler's service path). `sema.bounds.loops`' fate: read its
   clause text at execution; if it demands proved bounds it stays gap
   with an updated note (bound proving is deferred cleverness); the
   *checkpoint* half is what M6 delivers.
7. **Vector delivery** (06 §4): per-core pending word page (the
   machine contract grows it — wrela-machine constants, coherent with
   existing pages); the VMM raises by store + wake; the guest observes
   only at checkpoints/parks via mask–arm–recheck. M6's real injector
   is the **deadline service**: a parked guest writes its next deadline
   to the info page (06 §5); the VMM wakes it at that deadline; an
   expired group's cancellation is delivered as a vector observed at
   the target's next checkpoint. Flip witness for
   `machine.interrupts.checkpoint-injection`: a golden where a child
   spins in a bounded loop past its group's deadline and the transcript
   proves cancellation landed exactly at a checkpoint (deterministic
   iteration count — replay-identical), not mid-instruction.
8. **Cancellation/teardown subset** (02 §9.5, 04 §4): cancel closes
   admission, cancels children, runs ready `defer` cleanup in reverse
   source order, resolves `Cancelled` to the parent when the cleanup
   graph is empty. No device receipts exist yet, so the teardown graph
   is defers + child joins only. `CallError` variants erased per
   whole-image analysis where provable; at M6 erase only the trivially
   erasable (no deadline anywhere → no DeadlineExceeded, etc.),
   recorded.
9. **The recorder's choice sequence**: the record file becomes a
   sequence of explicit choice points — at M6, each admission event is
   recorded as (mailbox, chosen sender) even though exactly one
   candidate exists on one core, plus clock reads and deadline wakes.
   Replay consumes choices in order and diverges loudly on mismatch.
   The FORMAT (choice-tagged, enumerable — a later milestone can swap
   the chooser for an enumerator) is the deliverable ROADMAP's
   constraint names; pin it as a golden (`--record` of a fixed boot,
   with clock values normalized out of the pinned form — pin structure,
   not timestamps: the golden records a REPLAY file of a recorded boot,
   which is fully deterministic byte-wise given the recording... decide
   the dumbest pinnable form at execution and record it).
10. **diff-eval and async**: the evaluator does not execute async (M3
    scope). Comptime-legal tests stay the diff-eval corpus exactly as
    at M5; async runtime tests are backend-only and get no evaluator
    twin — recorded in the clause note, not a weakening (nothing that
    CAN run in both tiers stops being compared).
11. **`now()`/`ms()`**: compiler-recognized intrinsics (prelude-style,
    the img.* precedent): `ms(n)` pure comptime-legal duration
    constructor; `now()` runtime-only (illegal in comptime contexts —
    legality arm), lowering to the clock MMIO load. This flips
    `machine.clock.trap-logged` + `machine.replay.clock-log` with real
    golden-visible reads (deterministic transcripts must not PRINT raw
    clock values — tests use now() only for deadlines/durations
    compared against ms() constants, never printed).
11b. **Runtime tests reach actors via declared `Actor[T]` parameters**
    (decided 2026-07-24 at item-D verification; normative sentence added
    to 02 §12.2 in the same commit as clause
    `comptime.tests.runtime-actor-params`; REVIEW-QUEUE carries the
    audit line). Item D surfaced the underdetermined fork honestly: no
    doc-backed path existed from a zero-argument runtime test to an
    image-declared actor instance. Chosen rule: a `@test(runtime)` fn
    may declare `Actor[T]` params; the runner supplies the unique
    declared instance's handle; zero/multiple instances of `T` fails
    the build naming candidates. Rejected alternative: a compiler
    intrinsic `actor[T]()` inside test bodies — new expression surface
    where the parameter-list precedent (`@test(exhaustive)`: params
    declare what the harness supplies) already carries the meaning.
    Items D/F implement; the sema side must extend `test_attr_kind`'s
    runtime arm (params allowed, `Actor[T]`-typed only, mode Read).
12. **Abandon = image-fatal at M6** (no restart runtime): an actor
    turn that aborts (assert/overflow) prints the FAILED line (test
    root) or a named actor-fault line (actor turn), then the image
    exits nonzero deterministically. Restart mechanics arrive with
    M7+; the M4-checked supervision graph is carried in the report
    unchanged. Recorded so nobody mistakes it for the doc's restart
    semantics.
