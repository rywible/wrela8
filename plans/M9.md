# M9 plan: the stdlib

**Status: ACTIVE.**

First deliverable of the milestone, per the planning convention. The docs
carry the substance — [05-library.md](../docs/language/05-library.md) is
this milestone's chapter almost end to end, with
[02-language.md](../docs/language/02-language.md) §1.1 (literals), §2
(the fixed prelude), §7.4 (operator desugaring, `?` and `from`) and
[04-compiler.md](../docs/language/04-compiler.md) §2 (`@layout_assert`)
as its dependents — and [ROADMAP.md](../ROADMAP.md) M9:

> Lands: the `Format` contract and f-strings (dead in sema since M2),
> `Result`/`from` conversion, the collection/format/time surface of 05,
> and the `ImageReport` reflection type `@layout_assert` needs to run at
> all. Two structural consequences worth more than the features:
> `sema/prelude.rs` is **deleted**, and the doc corpus becomes
> sema-checkable. Flips: `comptime.fstring.bounds`,
> `image.report.layout-asserts`, `values.resource.protocol-consumption`.

## Where this milestone actually starts (measured, 2026-07-25)

Stated as numbers so the first item cannot begin by rediscovering them.

- `stdlib/` is **one file**: `stdlib/README.md`. There is no `core`, no
  module, no loader path, no wrela source compiled from it — ever, by
  anything.
- `crates/wrela-compiler/src/sema/prelude.rs` is **218 lines** of
  hardcoded names in four fixed arrays (`SCALARS`, `OPTION_RESULT`,
  `LITERAL_SURFACE`, `IMAGE_BUILDER`), whose own header calls itself "not
  the stdlib" and names this milestone as its executioner.
- f-strings are `error[unimplemented]` at **three** sites in
  `sema/bodies.rs` (lines 1338, 1496, 2141 at `13a3b41`).
- `cargo xtask corpus` reports `lexed 31, parsed 24, fragments skipped 7`
  — the normative chapters are parser inputs, not typed ones.
- `values.resource.protocol-consumption` is **already `test`**. ROADMAP
  names it as an M9 flip; it was flipped earlier. M9 owes it nothing but
  a re-check that it still holds once the stdlib supplies the types it
  talks about. Recorded here so the milestone is not credited for work
  it did not do.
- The two clauses M9 genuinely flips are therefore `comptime.fstring.bounds`
  and `image.report.layout-asserts`, both `gap` today.

## Goal

The standard library exists as **wrela source in `stdlib/`**, compiled by
the same pipeline as user code, dumped at every stage, and pinned by the
same goldens. The compiler stops carrying a hardcoded stand-in for it.
The normative chapters stop being lexer inputs and start being
type-checked ones, which is what makes ground-truth rule 1 ("if code
disagrees with the docs, the code is wrong") mechanical rather than
aspirational.

## The honest scope line (decide once)

IN: a `stdlib/core` that the compiler loads as ordinary wrela source, and
the loader path that finds it; the `Format` contract, `deriving(Format)`,
and f-strings with their summed `String[..N]` bound; `from` conversion
and `deriving(From)` as `?` consumes it; the collection surface of 05 §7
(`List`, `SlotMap` and its three-field key discipline, array
`map_take`/`try_map_take`, the two iteration forms); the time surface of
05 §5 (`Duration`, `Instant`, `now()` as a recorded effect); the
`ImageReport` reflection type and `@layout_assert` actually running;
deleting `sema/prelude.rs`; making the doc corpus sema-checked.

OUT (each fails closed, named, with the owner that would take it): SIMD
(05 §8.1 — a closed vector set and a NEON lowering contract, which is a
backend milestone's worth of work and is named by neither ROADMAP M9 nor
this plan's exit criteria); `race` (05 §4 — a sealed contract with
build-proven slot reservation and full loser teardown; `group` already
exists from M6 and `race` is not a stdlib type but a compiler contract);
`SlotMap.reserve()/slot.resolve()`'s turn-splitting service idiom (05 §4
— it generates a later turn, which is M10's runtime territory); a second
device family; runtime-in-wrela (M10); the cost contract (M11).

**Deliberately undecided until item C measures it:** whether
`Validated[F, T]` / `Secret[T]` (05 §6) land here. M8's carry-forward
table recorded them as "stdlib-era (ROADMAP M9)", but ROADMAP's own M9
paragraph does not name them and `values.marked.mechanism` rejects them
today. They are ordered as item G *after* `Format`, because `Secret` is
defined by having no `Format` and cannot be specified before `Format`
exists. If item G balloons past one session it splits per the
item-balloons rule, and the residue is named in the plan rather than
half-built.

## Shape decisions (frozen by goldens — decide once)

1. **The stdlib is wrela source, not a Rust table.** `stdlib/core/*.wr`
   is compiled by the ordinary pipeline. A stdlib type that cannot be
   written in wrela is a finding about the language, to be recorded and
   escalated in this plan — never a reason to reach back for a hardcoded
   entry. The exception set is exactly the intrinsics 05 §9 already names
   as compiler-recognized (`Image` and the builder surface), which are
   recognized *by name* in sema and whose surface may be declared in
   wrela without a body.
2. **The prelude becomes a loaded module, and then stops existing.**
   `sema/prelude.rs` is deleted in one commit, at the end, after every
   name it lists has a real definition. It is not whittled down in
   fifteen commits; a half-deleted prelude is two sources of truth.
3. **The corpus flip lands behind a flag first.** Per GOAL's standing
   risk note, which this plan restates so it is not rediscovered:
   sema-checking the docs will surface a batch of real doc/compiler
   disagreements at once, and a batch that size is exactly where
   ground-truth rule 1 gets quietly inverted to make the build green. So:
   land the flip off by default, fix each disagreement in its own small
   cited commit with the docs winning by default, and only then make
   corpus sema-checking mandatory in `check`. **Never `golden --update` a
   batch that has not been read case by case.**
4. **A doc/compiler disagreement is resolved in favour of the doc**
   unless the doc is internally inconsistent, in which case the tiebreak
   is GOAL's: prefer the reading consistent with the ledger and existing
   goldens, make the minimal doc fix, same-commit clause, REVIEW-QUEUE
   line. Every such fix is its own commit. The count of them is evidence
   and goes in the closing block.
5. **f-strings are bounded at build time or they are a build error.**
   05 §6: `f"..."` sums each operand's `max_formatted_len(spec)` into
   `String[..N]`. There is no dynamic fallback and no truncation; a
   `Format` implementation that cannot state a bound cannot be used in an
   f-string. `panic`'s formatter keeps its own fixed maximum and a
   message that cannot fit stays a build error.

## Work items, in order

Progress (ticked in the same commit as the work):

- [ ] A. **The loader path.** `stdlib/core/` exists and the compiler
      compiles it as ordinary wrela source ahead of the user module;
      `wrela dump --stage=<s>` reaches stdlib code. No new types yet —
      this item moves *one* existing prelude name (`Option`, the smallest
      real one) out of `prelude.rs` and into `stdlib/core/option.wr`, and
      proves the mechanism end to end. Everything else depends on it.
      Goldens: `check-stdlib-loaded`, `err-stdlib-missing`.
- [ ] B. **`from` conversion and `deriving(From)`** (05 §8, 02 §7.4).
      `?` already converts through `from` where the types differ; this
      item gives it the declared surface and the deriving. Ordered before
      `Format` because `Format`'s error paths use it.
      Goldens: `check-deriving-from`, `err-deriving-from-two-fields`.
- [ ] C. **The `Format` contract and `deriving(Format)`** (05 §6).
      `max_formatted_len(spec)` as a comptime-evaluated bound plus a
      writer that provably cannot exceed it; exceeding a proven bound is
      abandonment. Goldens: `check-format-bound`,
      `err-format-exceeds-bound`.
- [ ] D. **f-strings** — the three dead sites in `sema/bodies.rs` come
      alive; `f"..."` sums its operands' bounds into `String[..N]`.
      **Flips `comptime.fstring.bounds`.** Depends on C.
      Goldens: `check-fstring-bounds`, `err-fstring-unbounded-operand`,
      `err-fstring-secret` (once G decides `Secret`; otherwise the case
      is written against a type with no `Format` at all).
- [ ] E. **Time** (05 §5). `Duration` with checked constructors and
      `add`/`subtract`/`less_than`; `Instant` opaque and monotonic;
      `now()` as a sealed effect forbidden in comptime and ISR context
      and **recorded/replayed** — the recorder already has `ClockRead`
      from M6, so this item wires the stdlib surface onto an existing
      choice entry rather than inventing one.
      Goldens: `check-duration-arith`, `err-now-in-comptime`,
      `err-now-in-isr`, `boot-instant-monotonic`.
- [ ] F. **Collections** (05 §7). `List[T, ..N]`, `SlotMap[T, ..N]` with
      the `(map_id, index, generation)` key discipline (foreign and stale
      keys *miss*, never alias; `GenerationExhausted` never wraps), array
      `map_take`/`try_map_take` with `try_map_take`'s unwind-and-reclaim
      on `Err`, and the two iteration forms (owned `for`, lent
      non-suspending closures).
      Goldens: `check-slotmap-key-discipline`, `err-slotmap-stale-key`,
      `check-try-map-take-unwind`, `err-each-suspends`.
- [ ] G. **Marked values** (05 §6) — `Untrusted[T]`, and the decision on
      `Validated[F, T]` / `Secret[T]` recorded either way. See the
      honest-scope note above: this item may split, and if it does, the
      split is committed to this file before the work continues.
- [ ] H. **`ImageReport` reflection + `@layout_assert` runs.** 04 §2's
      layout assertions have been registered by `img.check_layout(f)`
      since M4 and have never executed, because the reflection type they
      read did not exist. **Flips `image.report.layout-asserts`.**
      Goldens: `check-layout-assert-passes`,
      `err-layout-assert-fails`.
- [ ] I. **Delete `sema/prelude.rs`** (shape decision 2), in one commit,
      once every name it carries has a real definition. The `IMAGE_BUILDER`
      array is the interesting half: those names must stay recognized as
      intrinsics (05 §9) while ceasing to be a hardcoded scope.
      Goldens: the whole existing suite is the oracle — nothing may move.
- [ ] J. **The corpus flip**, in the three commits shape decision 3
      requires: (J1) sema-check the doc corpus behind an off-by-default
      flag and report the disagreement count without failing; (J2) fix
      each disagreement in its own small cited commit, docs winning by
      default, REVIEW-QUEUE line for every normative edit; (J3) make
      corpus sema-checking mandatory in `cargo xtask check`.
      Depends on A–I.
- [ ] K. **Sweep + soak + finalization.** Adversarial sweep — and per
      M8's closing lesson, the sweep's targets are written as *properties*
      rather than cases, because a directed sweep's default failure mode
      is closing exactly the case it was shown. Named attack list to be
      appended as items land, seeded with: a `Format` bound that is
      provable but wrong; an f-string whose summed bound overflows; a
      `SlotMap` key forged across two maps; `now()` reached from a path
      no check covers; a `@layout_assert` that passes vacuously. Then:
      deep fuzz every live lane, 3+ fresh seeds, from a **release** build
      of the harness; write `plans/M10.md`; mark complete.

## Exit criteria (mechanically checkable)

- `cargo xtask check` green.
- `crates/wrela-compiler/src/sema/prelude.rs` **does not exist**.
- `stdlib/core/` contains compiled-and-tested wrela source; at least one
  golden dumps a stdlib-defined type through `wrela dump`.
- `comptime.fstring.bounds` flips `gap` → `test`.
- `image.report.layout-asserts` flips `gap` → `test`.
- `values.resource.protocol-consumption` re-verified `test` against the
  real stdlib types (no flip owed; see the starting-state note).
- `cargo xtask corpus` sema-checks the doc corpus and that check is
  **mandatory in `check`** — the `fragments skipped` count may be
  nonzero, but `parsed`-only must be gone.
- Deep fuzz all live lanes, 3+ fresh seeds, clean, release harness.
- `plans/M10.md` does not exist yet.

## Non-goals (M10+ territory)

service idiom that generates a turn; runtime-in-wrela (M10); the cost
contract (M11); display/input (off the ladder — ROADMAP's recorded
intentions, human-gated); a fourth vCPU; a second device family.
