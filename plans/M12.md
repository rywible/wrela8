# M12 plan: the representation rung (placed statics back to O(1))

**Status: ACTIVE (2026-07-26).** Activated by item 0 after M11 close.
Decision block 870–899 reserved for this rung.

Provenance: this rung and its sibling `plans/M13.md` were one draft
plan, split on external review (2026-07-26): the two halves share no
oracle, no golden surface, and no dependency — this half is
byte-identical-transcript representation work, the direct continuation
of M10 item 0 and M11; the other half is vocabulary and doc-revision
work. One milestone churning the same report/asm goldens from two
independent workstreams would have destroyed the review surface, and
the combined item count was roughly double the largest prior rung.
Every file:line anchor below was verified on this tree at M11 item J
close; if an anchor has moved by activation, re-verify the fact, not
the conclusion.

The rung's one-sentence doctrine: **every runtime-varying reference is
an index into a statically-sized, uniformly-strided array — with no
exception carved out by numbered names.** M11's rule holds for data
and is faked by `RING0..7`, `INIT_SLOT0..31`, `WAKE_PEND0..7` wherever
the element is a placed region; this rung makes it hold for real. The
exit criterion is one number: the placed-static count, ratcheted.

**One exception to "representation only," owned here rather than
smuggled:** item B (`@budget(bound=NAME)`) is a normative 02 §8.1/§13
language edit. It rides this rung because `runtime.wr`'s loop bounds
currently shadow the Rust consts this rung's representation work
touches — connecting them is a prerequisite of honest ring/init
convergence, not vocabulary work. Everything else language-shaped
belongs to `plans/M13.md`.

## Where this rung starts (verified anchors, 2026-07-26)

### Runtime shape

- Generated placed statics are **O(image)**: `RING{0..7}_CTL`,
  `RING{0..7}_DATA` (per-edge `slot_words` 2–4, per-edge capacity —
  the variable strides that force separate statics), `INIT_SLOT{0..31}`
  (per-actor zero overlays, `rtconfig.rs:701–705`), `WAKE_PEND{0..7}`
  (one word each, `rtconfig.rs:723`), plus `RT`, `SCHED`, `GROUPS`,
  mailbox overlays, and the seven handwritten machine pages. Accessor
  ladders exist solely to reach the numbered statics
  (`__wrela_ring_{get,set}_{head,tail,count}`, `ring_{load,store}_word`,
  `__wrela_wake_pending_{load,store}`, `__wrela_init_store_word`).
- The per-edge `__wrela_xsend_0..7` trampolines (`runtime.wr`, decision
  802) bake a comptime edge constant into a BL target — **dispatch**,
  not data; they stay. Consequence recorded up front: **item C does
  not retire `RING_POOL_COUNT = 8`** — after the data ladders die, the
  cap survives for a different reason (the trampoline pool is
  dispatch), and item A's clause note must say so rather than leaving
  it looking like scaffolding this rung retires.
- Generator cap constants live in Rust with no normative sentence:
  `RING_POOL_COUNT = 8`, `ENQUEUE_STUB_COUNT = 32`,
  `BOOT_CALL_POOL_COUNT = 32`, `IRQ_CALL_POOL_COUNT = 8`,
  `WAKE_CALL_POOL_COUNT = 8`, `SELECT_STUB_COUNT = 32`,
  `RESUME_STUB_COUNT = 16` (`rtconfig.rs:92–104`). All fail closed.
- `GROUP_MAX_CHILDREN = 2` (`codegen.rs:6001`), enforced fail-closed at
  `codegen.rs:6096` (>2 `g.start`) and `:8069` (`join_all`), while
  02 §9.5's normative example writes `capacity=4` (passing only because
  it starts two). Semantics in a Rust const contradicting a normative
  example — distinct from the honest scaffolding caps above.
- `RTDATA_BASE = IMAGE_BASE + 128 KiB` (ratcheted from 64 KiB at M11
  item H, decision 818, when generic runtime bodies overflowed);
  `RTDATA_SIZE_MAX = 256 KiB` (06 §2). Padding added by this rung
  spends against that cap.

### Loop bounds

- Sync loops require `@budget(bound=N)` with **N an integer literal
  only** (`sema/bodies.rs:~2338`, `Expr::Int` match). The machinery to
  resolve a `const` name to a comptime integer already exists for
  `@layout(runtime)` array lengths (`sema/types.rs:1810`, `2106`,
  `3244` — the layout-completion pass, decision 581). `runtime.wr`'s
  ring/slot loops hardcode `bound=8` / `bound=32`, shadowing
  `RING_POOL_COUNT` / the init and boot pool counts — the bound lives
  in two places and the language currently forbids connecting them.

### Bench

- Guest lock `boot-actors` 700000us, measured 63639us at M11 item 0.
  Layout-assert code cap 160000 (measured 118200 at item J).

## Shape decisions this rung freezes (do not relitigate mid-item)

Decision numbers: this plan reserves **870–899** (`plans/M13.md`
reserves 900–999).

1. **Uniform ring stride.** Ring ctl words become one contiguous
   `[RingCtl; N_RINGS]`; ring data is padded to the image-wide maximum
   `slot_words` × maximum capacity, becoming `[[u64; RING_STRIDE];
   N_RINGS]`. Bytes are spent to buy a type (the M10 turn-area trade);
   the report prints the padding cost. Per-edge `capacity`/`slot_words`
   remain generated scalar facts. Dispatch ladders and trampolines
   stay; **data ladders die** — the facts-only clause gains the
   sentence: *a generated dispatch ladder is forced; a generated data
   ladder is a defect.*
2. **The named fallback** (per review — M10's turn-area trade named
   one and this trade must too): if uniform padding multiplies badly,
   the fallback is a generated **offset table** — one extra load,
   still an index, still one static, still no ladder. It is not taken
   automatically: item C measures padding over the golden corpus and
   fails closed at layout (with the measured number in the
   diagnostic) if `rtdata` would exceed `RTDATA_SIZE_MAX`; choosing
   the fallback is then a human decision recorded here, not an
   in-item swerve. Precedent: M11's `RTDATA_BASE` ratchet (decision
   818) was exactly this shape of measured, disclosed adjustment.
3. **Placed-static census.** After this rung the placed-static count
   is a report line and an `xtask check` ratchet with a fixed bound
   independent of image size (fixed set + coalesced init spans).
   Modeled on `emitted_a64_census.rs`.
4. **`@budget(bound=NAME)`** accepts a name resolving to a
   module-level (or imported) `const` of integer type with comptime
   value ≥ 1, resolved by the same completion pass as
   `@layout(runtime)` array lengths — deliberately the identical rule,
   so the language keeps one answer to "when may a bound be a name"
   (03 §3.1's wording is reused verbatim).

## Exit criteria (mechanically checkable)

- `cargo xtask check` green; bench locks unchanged or re-locked with
  the delta recorded (this rung may move code size; record it).
- Placed-static census line present and ratcheted; `RING{i}_`,
  `WAKE_PEND`, `INIT_SLOT` numbered statics absent from generated
  rtconfig on every golden.
- Ring padding cost printed in every report's rtdata section; no
  golden image exceeds `RTDATA_SIZE_MAX`.
- 02 §9.5's `capacity=4` example compiles and runs in a pinned golden
  (`boot-group-four-children`).
- Ledger: `actors.groups.child-capacity` flipped to `test`;
  `runtime.rtdata.placed-static-census` present as `test`;
  `sema.bounds.loops` note updated for the const-name bound.
- Every boot transcript in the golden corpus byte-identical to its
  pre-rung state (the rung-wide oracle).
