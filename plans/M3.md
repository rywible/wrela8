## Goal

The language is alive with zero emitted instructions: comptime-legal wrela
evaluates in the build under quotas; `comptime if` specializes and
`comptime assert` proves; `@test` functions with comptime-legal closures
run as build-time tests with a pinned, deterministic report. The substrate
is the **typed tree** — sema stops returning only a verdict and starts
producing the checked program every later consumer (the evaluator now,
FlowWir at M5) reads instead of re-deriving.

## Shape decisions (frozen by goldens — decide once)

1. **The typed tree** is sema's product, not an IR. Plain-enum mirror of
   `Expr`/`Stmt`/declarations — no lowering, no CFG, no SSA, no node IDs,
   no arena. Every expression node carries its resolved `Type`; calls
   carry a by-value callee key (dotted path, or (generic, instantiation
   args) key); desugared operators are already method-call nodes (builtin
   scalar ops stay primitive nodes); literals carry their settled scalar
   type; `?` stays one node carrying its conversion-target key; enum
   constructions carry (enum, variant) resolved; closures carry their
   structural fn type. Produced by the bodies pass (its `check_expr`
   returns a typed node instead of a bare `Type`); access/flow/matches
   keep consuming the AST — they are not retrofitted in M3 (a recorded
   non-goal; access.rs's tracker migrates first whenever it is next
   forced open).
2. **`wrela dump --stage=typed`** pins the tree: one node per line,
   two-space indent, `Kind key=value ty=<type>` in the M1 dump style, no
   spans. Golden coverage via the existing touch convention — typed
   expectations are pinned for the `check-*` cases that earn them, not
   all 100 goldens.
3. **Typed-roundtrip oracle**: `typed(x) == typed(pretty(parse(x)))`
   byte-for-byte, replacing the check-dump comparison as the sema
   agreement oracle in `xtask roundtrip` and the fuzz sema invariant —
   strictly stronger, same machinery.
4. **The evaluator walks the typed tree only.** It re-derives nothing —
   no name resolution, no typing, no desugaring. A fact the evaluator
   needs but the tree lacks is a bug in the producer: fail closed
   (`error[unimplemented]`), never look back at the AST.
5. **Values are one plain enum**: scalars (stored at target width,
   arithmetic per 02 §6.1 — ordinary ops abandon on overflow, `+%` peers
   wrap, division/shift rules exact), bool/char/unit, tuples/arrays as
   `Vec<Value>`, structs as field-ordered `Vec<Value>`, enums as
   (variant index, payload values), `Static[Str]`/`Bytes` as owned
   bytes, named functions as callee keys. Comptime abandonment (overflow,
   failed assert, out-of-bounds, explicit `panic`) is a **build error**
   naming the operation and carrying the comptime call stack.
6. **Quotas**: finite step and memory budgets, fixed constants in
   revision 0.1 (build profiles arrive with the manifest, M4); every
   evaluator loop iteration and call costs steps; exceeding a quota is a
   build error with the hottest stack (04 §8). No wall clock anywhere.
7. **Comptime legality is inferred, whole-graph** (02 §12): a `fn` is
   comptime-callable when its transitive callee closure — computable
   directly from typed-tree callee keys — is deterministic and free of
   I/O, async/actor operations, and hardware effects. In M3's world the
   illegal set is exactly: `await`/`send`/actor calls, `with`
   group/pool, pool operations, `@image` bodies, and anything still
   fail-closed. Violations are diagnosed with the offending call path
   (the generics chain-diagnostic precedent).
8. **`comptime if` specializes between declare and bodies**: its
   condition must be comptime-evaluable with the real evaluator
   (consts, literals, calls to comptime-legal fns); the unselected branch
   is dropped before body checking, so the graph that is checked is the
   graph that exists (02 §12). Module-scope, member-scope, and
   statement-position forms all land. `comptime assert` evaluates after
   typing; failure is a build error with the message.
9. **`@test` comptime tier**: `wrela test <file.wr>` runs every `@test`
   zero-argument fn whose closure is comptime-legal, in declaration
   order, each under its own quota; output is a deterministic report
   (`test <name>: ok` / `test <name>: FAILED <diagnostic>`, summary
   line), pinned by goldens. `@test(runtime)` and comptime-illegal test
   closures fail closed naming M5. Test failures exit nonzero; the
   report is still the stable dump.
10. **What stays fail-closed in M3** (each a named diagnostic):
    f-string bound computation (needs the stdlib `Format` contract —
    stdlib milestone; gap `comptime.fstring.bounds`), `@image` bodies
    (M4), imports (manifest milestone), `checked_to`/`truncate_to`
    (need a stdlib error type), generic methods' own type parameters
    (existing documented boundary), `@test(runtime)` (M5).
11. **Code layout**: typed tree types in
    `crates/wrela-compiler/src/sema/typed.rs` (produced by bodies.rs);
    evaluator in `crates/wrela-compiler/src/eval/` — `mod.rs`,
    `value.rs`, `interp.rs` (one obvious walk), `legal.rs` (legality
    inference), `quota.rs`. Long obvious files, clone freely,
    BTreeMap everywhere output-touching.

## Work items, in order

### A. The typed tree
bodies.rs produces it; `--stage=typed` dumps it; the typed-roundtrip
oracle replaces the check-dump comparison; generics' instantiation
checking stores each instantiation's typed body under its key. Typed
expectations pinned for a representative golden set (bodies, operators,
generics, one torture program). Opens: `sema.typed.dump-stable`,
`sema.typed.roundtrip`.

### B. Evaluator core
`eval/` walks typed bodies: literals, locals, arithmetic per 02 §6.1
with target widths, calls (direct + instantiated + methods + `init`),
struct/enum/tuple/array construction and access, `match`/`is`, loops,
closures (non-escaping, direct application), `defer` (runs at scope
exit in reverse order), `?` with `from` conversion, `take`/moves (values
move by Rust move — flow already proved legality), `assert`, `panic` as
abandonment. Quotas per decision 6. There is no `--stage=eval`: the
evaluation surfaces are `comptime assert`, `comptime if` conditions,
const initializers, and `wrela test` — each already a pinned output.
Const initializers evaluated with the real evaluator replace M2-H's
literal-only subset (const-arg generic instantiation now evaluates real
expressions). Opens: `comptime.eval.scalar-exact`,
`comptime.eval.abandonment-is-build-error`, `comptime.eval.quotas`.

### C. Legality inference
Whole-graph comptime-callable classification over typed callee keys with
call-path diagnostics; `comptime assert` and `comptime if` conditions and
const initializers require legal closures. Opens:
`comptime.legality.inferred`.

### D. `comptime if` specialization + `comptime assert`
Both forms land per decision 8; sema's fail-closed on them lifts;
exhaustiveness re-checks after specialization (02 §7.2's "checked after
comptime specialization" becomes literal). Opens:
`comptime.specialize.selected-branch-only`,
`comptime.assert.build-error`.

### E. `@test` comptime tier
`wrela test` CLI + report format per decision 9, wired into xtask
(`xtask check` runs `wrela test` over a tests-bearing golden corpus
subset; the report is a golden). The torture corpus grows `@test`
functions that actually compute — the evaluator's acceptance suite.
Opens: `comptime.tests.build-tier`.

### F. Hardening + measurement
`cargo xtask fuzz eval`: corpus-mutation inputs that typecheck get their
comptime-legal `@test`s/const initializers evaluated under a small
quota; invariants — never panics, deterministic across two runs,
always terminates within quota, abandonment is always a diagnostic.
Bench compiler grows an eval lane (evaluate the test-bearing goldens,
locked threshold). Opens: `comptime.eval.no-panics`. Updates the bench
clause note.

### G. Error-corpus sweep
Adversarial pass over the new surface (haiku tier): quota exhaustion,
recursion, abandonment paths, illegal-closure diagnostics, comptime if
condition errors, specialization edge cases (both branches ill-typed,
selected branch empty). Wrong evaluation *results* hunted with
hand-computed expected values in `@test`s. Any find minimized and pinned
before its fix lands.

## Non-goals (M4+ territory)

No image evaluation or `Image` builder intrinsics (M4), no manifest or
build profiles (fixed quota constants instead, M4), no
content-addressed comptime caching (04 §8 allows it; the cleverness
budget prices it — needs a compiler-lane profile first), no backend or
diff-eval (M5 — the evaluator IS the reference; its second opinion
arrives with the backend), no runtime tests (M5), no retrofit of
access/flow/matches onto the typed tree, no f-string bounds (stdlib
milestone), no evaluator performance work beyond the bench lock.
