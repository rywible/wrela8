## Goal

Land entropy as a **thin recorded device** — clock-shaped, not
blk-shaped:

1. VMM model: live host entropy on record; replay from the choice log;
   fail closed on underrun (clock underrun is the precedent).
2. Sealed guest effect `entropy[N]() -> Bytes[N]`, illegal at
   comptime/ISR like `now()`, lowered to a park-shaped trapping MMIO
   fill (no virtqueues).
3. Boot golden + `xtask repro` tamper lane that diverges if bytes are
   not logged/replayed.
4. Normative 05/06 surfaces: drop "lands M17" placeholder; name the
   frozen effect.

**Not a `@driver`.** Does not add modules under `stdlib/drivers/`.

### `Bytes[N]` layout fact (load-bearing for lowering)

- Exact `Bytes[N]` is **slot-per-byte** (`mwir::size_of`: `8 * N`,
  `mwir.rs` ~994–1006; codegen decision 596).
- Unbounded `Bytes` is packed `(base, len)` handle (decisions 595–596).
- Entropy fill therefore uses a **packed scratch** the VMM writes, then
  codegen expands into `Bytes[N]` slots. Do not invent a second
  `Bytes[N]` layout.

## Shape decisions this milestone freezes (do not relitigate mid-item)

Decision numbers: this plan reserves **1200–1299**.

1. **Guest API = option A.** Spelling: `entropy[N]() -> Bytes[N]` with
   comptime integer literal `N` in **`1..=64`**
   (`ENTROPY_LEN_MAX = 64`). No arguments inside `()`. Parses as
   `Call(Index(Name("entropy"), [N]), [])` — same Index-then-Call shape
   as `img.pool[T](...)` / `x.to[T]()`
   (`sema/bodies.rs` `check_call_index` ~5559). Sema gains a bare-name
   `entropy` arm there (before generic fallthrough).
2. **Illegal like `now()`.** Comptime + ISR refuse with named reasons
   (`eval/legal.rs` grows `Effect::Entropy` parallel to `Now`). Bottom
   half: same answer as `now()` unless 03 §6 already admits clock reads
   there — mirror `now()` exactly; do not invent a third rule.
3. **Machine contract = park-shaped fill, not a single load.**
   - `mmio::ENTROPY_MMIO_ADDR = MMIO_BASE + 0x5000` (next free page after
     quiesce; one page per register convention).
   - `machine_info::OFF_ENTROPY_DEST = 0x318` (u64 GPA),
     `OFF_ENTROPY_LEN = 0x320` (u64 length) — first free slots after
     `OFF_TEST_LINE_BUF` (0x218 + 256 = 0x318). Update the
     `machine_info_fields_fit_*` unit test.
   - Protocol: guest writes dest GPA + len (ordinary stores), then
     trapping **store** (any value) to `ENTROPY_MMIO_ADDR`. VMM reads
     dest/len from machine-info, fills `[dest, dest+len)` with entropy
     bytes, logs one choice, advances PC. Store to clock-shaped entropy
     without the staging writes, or a load of `ENTROPY_MMIO_ADDR`, is a
     guest fault.
4. **FlowWir-only lowering (same floor as `now()`).** `FlowInst::Entropy
   { dst, n }`; `codegen::emit_entropy`. Sync MWIR path fails closed if
   reached (do not silently no-op). Goldens use `async` `@test(runtime)`
   / async actor methods, mirroring `boot-instant-monotonic`.
5. **Codegen shape for `emit_entropy(dst, n)`:**
   1. Allocate `n` packed scratch bytes on the frame (contiguous).
   2. Store scratch GPA → `OFF_ENTROPY_DEST`; store `n` →
      `OFF_ENTROPY_LEN`.
   3. Trapping store to `ENTROPY_MMIO_ADDR`.
   4. Expand: for `i in 0..n`, load byte `scratch[i]` into
      `Bytes[N]` slot `i` of `dst` (slot-per-byte layout).
6. **Choice log tag.** `ChoiceEntry::EntropyRead { bytes: Vec<u8> }`
   (and matching `ChoiceRequest::EntropyRead { len: u64 }`). Text form:
   `EntropyRead len=<n> hex=<2n lowercase hex chars>`. Parse fails
   closed if `hex` length ≠ `2 * len` or `len` ≠ request. Underrun /
   tag-mismatch fallback: `len` zero bytes (clock's `value: 0`
   precedent — boot completes; divergence list diagnoses). **Stay on
   `ChoiceLog v1`** — additive tag, same as prior tags; update the
   format-pin unit test that lists every tag.
7. **Live host entropy.** Read exactly `len` bytes from `/dev/urandom`
   (`std::fs::File` + `Read::read_exact`). No new crate. Fail closed on
   short read / open error (VmmError, not silent zero-fill on the live
   path — zeros are **only** the replay underrun fallback).
8. **Fill path = `host_ram`, not `GuestMem`.** Stack scratch is not a
   DMA pool window; `GuestMem::window_offset` would refuse it. Validate
   `[dest, dest+len)` lies wholly inside guest DRAM
   (`DRAM_BASE .. DRAM_BASE+DRAM_SIZE`), then `copy_nonoverlapping` into
   `host_ram`. Out-of-range / overflow → guest fault. Document this in
   the handler the way park documents reading `OFF_NEXT_DEADLINE`.
9. **Typed node carries `N`.** Extend `TypedExprKind::Intrinsic` with
   `const_arg: Option<u64>` (None everywhere except `key == "entropy"`).
   Rejected: encoding N only in the key string; abusing `type_arg`.
10. **Oracles split like clock.**
    - **`boot-entropy`:** async runtime test calls `entropy[8]()`,
      touches every index, prints a **stable** line (e.g. `entropy:ok`)
      — does **not** print raw bytes (live nondeterminism must not break
      `expected/test.txt`).
    - **`xtask repro` entropy lane:** record a boot that **does** print
      hex of the bytes (can be the same image with a second test, or the
      same test if the golden runner never pins that print — prefer a
      dedicated `boot-entropy` that prints only `ok`, plus repro driving
      a small sibling `boot-entropy-hex` **or** the same binary under
      record/replay where the pinned golden ignores the record file).
      Freeze in item H commit: one named case whose live transcript
      includes hex is exercised **only** by repro (record → replay
      identical transcript; tamper first `EntropyRead` hex →
      `EXIT_REPLAY_DIVERGENCE`). Ledger cites the repro command + the
      boot source path.
11. **Docs.** 05 §5 (or a short § after time): name `entropy[N]() ->
    Bytes[N]`, bounds, comptime/ISR ban, recorded/replayed. 06 thin row:
    drop "lands M17"; guest surface `entropy[N]()`. No `stdlib/drivers/`
    mention for entropy. REVIEW-QUEUE line on the doc commit.
12. **Ledger clause ids (frozen):**
    - `machine.entropy.trap-logged` — open `gap` at A; flip when G+H
      prove a `.wr` guest issues the fill and the choice is logged
      (citability bar = clock's M6 flip).
    - `machine.entropy.replay` — open `gap` at A; flip when H's tamper
      lane is green (may share note text with
      `machine.replay.choice-sequence` growth — still its own id so the
      entropy surface is findable).
    - `library.entropy.effect` — open `gap` at A; flip when E+F land
      sema/err goldens + 05 text.
    - Update `machine.display.golden-frames` note: remove "until M17
      lands" once trap-logged flips (display/input stay pixels).

## Verification policy (cheap per item; expensive at close)

`cargo xtask check` is the gate. It is **too expensive to run after every
item.** Split:

| Lane | When | What |
| --- | --- | --- |
| **Cheap (required per item)** | Before that item's commit | Unit tests + dumps for **new/changed** behavior; named goldens the item touches; `cargo xtask ledger` / `corpus` when docs move |
| **Focused boot** | Items G / H only | Named `boot-entropy*` via the golden / repro paths alone — not the whole `boot-*` corpus |
| **Expensive (item I only)** | Milestone close | Full `cargo xtask check` |

**Rules:**

1. Every item's Cheap oracle must fail if the new behavior is wrong.
2. Do **not** run full `cargo xtask check` on items 0–H.
3. Item I is not optional. The rung is not COMPLETE until the expensive
   lane is green.
