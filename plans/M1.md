# M1 plan: parse everything

First deliverable of the milestone, per the planning convention: plans are
written when a milestone activates, never earlier. This plan is an ordered
walk through the clauses M1 flips or opens; the docs
([02-language.md](../docs/language/02-language.md)) carry the substance,
the doctrine ([ROADMAP.md](../ROADMAP.md)) carries the how. When M1 is
done, this file is history, not maintenance.

## Goal

Every ```wrela block in the docs and the full virtio example lex **and
parse** to a pinned AST dump; the lexer is complete and fuzz-hardened; the
parser never panics on any input; syntax errors are a golden corpus.

## Exit criteria

- `cargo xtask check` green with the corpus parse requirement enabled
  (`...` fragments stay lex-only; the virtio example contains none and
  parses fully).
- `cargo xtask fuzz lexer` and `cargo xtask fuzz parser` run clean at the
  deep budget; the smoke budget (fixed seeds, <1s) is wired into `check`.
- Every clause below flipped to `test` or opened-and-flipped.
- `plans/M2.md` does not exist yet.

## Shape decisions (these get frozen by goldens — decide once)

1. **Diagnostic format** stays exactly what the first golden already
   pinned: `error[<category>]: <message> at <line>:<col>`, one line, no
   source excerpt in v0. Categories so far: `lex`, `parse`.
2. **Error policy: fail-fast.** First error stops the stage. Recovery and
   multi-error reporting are features bought later with a profile of
   actual agent friction, not assumed now. One error per golden case.
3. **Spans** are `line:col` (u32 pairs) on every AST node, as in tokens.
   No byte offsets, no span interning.
4. **AST** is plain Rust enums/structs, one file, no arena, `Box` for
   recursion, `Vec` for sequences. Nothing generic.
5. **AST dump format**: one node per line, two-space indent for children,
   `Kind @line:col key=value`, string payloads quoted. Deterministic by
   construction (source order). Example:

   ```text
   Module @1:1 path=examples.tokens
     Const @3:1 name=LIMIT
       TypeName @3:14 name=u64
       IntLit @3:20 text=0x1000_0000
   ```

6. **Fuzzing is in-tree and deterministic**: a seeded xorshift generator
   in xtask (random bytes + token-soup + corpus-mutation strategies), not
   cargo-fuzz/libFuzzer (nightly + external engine = liabilities; revisit
   only if the dumb fuzzer stops finding bugs before the spec runs out).
   Every fuzz find is minimized by hand into a committed golden error
   case before the fix lands — crashes become regression tests, always.

## Work items, in order

### A. Lexer completion
Close the known gaps (each = clause + golden case):

| Clause | Work | Cases |
|---|---|---|
| `syntax.lexer.float-literals` | `digits.digits` with optional `e/E` exponent; digits both sides; underscore rule | `lex-floats`, `lex-float-errors` |
| `syntax.lexer.escapes` | validate `\\ \" \' \n \r \t \0 \xNN \u{...}` per context (text/byte/char) at lex time; reject the rest | `lex-escapes`, `lex-escape-errors` |
| `syntax.lexer.doc-comments` | `##` emits a `DocComment` token (attachment is the parser's job); `#` stays skipped | `lex-doc-comments` |
| `syntax.lexer.triple-quote-reserved` | `"""` is a named error, not an unterminated string | `lex-triple-quote` |
| `source.identifiers.ascii-only` (flip existing) | non-ASCII byte in identifier position gets a named diagnostic, not "unexpected character" | `lex-non-ascii-ident` |
| `syntax.lexer.fstring-braces` | `{{`/`}}` and balanced `{expr}` extents scanned (contents still raw for the parser) | `lex-fstring` |

### B. Lexer fuzzing
`cargo xtask fuzz lexer`: arbitrary byte strings + mutations of corpus
files. Invariants checked on every iteration — the lexer never panics;
output is either tokens or one `LexError`; INDENT/DEDENT balance; EOF is
last; token positions are monotonic. Opens `syntax.lexer.no-panics`
(tests: `xtask:fuzz` + the crasher-derived golden cases). Smoke budget
into `check`.

### C. Parser skeleton + dump
Recursive descent over the token stream, one module. Land the spine first:
`module` header, imports, and empty declarations, with
`wrela dump --stage=ast` and the first `ast-*` goldens pinning the dump
format (decision 5). Opens `syntax.ast.dump-stable`.

### D. Full grammar, corpus-driven
Work through chapter 02 construct by construct, letting the corpus be the
to-do list — a doc block that fails to parse is the next work item.
Order: declarations (`struct`/`resource struct`, `enum`, `fn`/`async fn`,
`init`, `pool`, `const`, `deriving`, attributes) → statements (`if`,
`match`/patterns, `for`/`while`, `defer`, `with`, `send`, assignment) →
expressions (precedence ladder of 02 §8.2, closures, `take`/`await`/`?`,
call arguments with `mut`/`take` mirroring) → f-string interpolation
extents. Opens one clause per area: `syntax.parser.declarations`,
`syntax.parser.statements`, `syntax.parser.expressions`,
`syntax.parser.patterns`, each with corpus + targeted goldens. Ends with
the corpus parse requirement enabled in xtask and
`docs.examples.wrela-blocks-parse` opened and flipped.

### E. Parser hardening
Two oracles beyond the corpus:

- **Fuzz**: `cargo xtask fuzz parser` — token-soup (random valid tokens)
  and corpus mutations. Invariant: never panics; always AST or one
  diagnostic in the pinned format. Opens `syntax.parser.no-panics`.
- **Roundtrip**: a dumb pretty-printer (`wrela dump --stage=pretty`) plus
  the property `parse(pretty(parse(x))) == parse(x)` over the whole
  corpus. This is the parser's `diff-eval` — a second implementation
  (printer) checking the first. Opens `syntax.parser.roundtrip`.

### F. Error corpus
One golden case per representative syntax error, named for its rule:
tab indentation (exists), bad dedent, five-space indent, unterminated
string/char/delimiter, keyword as identifier, missing `:`, missing label
mirror (`mut`/`take` at call sites is parsed syntax — a non-place operand
after `take` is a parse error), lone `else`, `...` outside a doc
fragment. Opens `syntax.diagnostics.parse-errors`.

## Non-goals (M2+ territory — reject nothing semantic)

No name resolution, no types, no access checking, no comptime evaluation.
The parser accepts semantically absurd but grammatical code
(`take 5` is a parse error; `take undefined_name` is not). No error
recovery, no incremental reparsing, no parser performance work — though
`bench compiler` comes alive at the end of M1 (per ROADMAP) and locks the
first threshold over the corpus.
