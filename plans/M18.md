## Goal

Ship a deterministic **proxy-cycle** ruler for **ranking** emitted code
— nothing else:

1. Versioned `wrela-cost-v1` — ISA op-class **latencies** (+ optional
   model `issue_width`), not an A76 absolute µarch table.
2. **Emit-time `CostRule` + dest/src regs** on every codegen word
   (always on; no profile toggle) — never parse mnemonics.
3. Dumb **register scoreboard** over the final per-fn stream (same
   pipeline as `--stage=asm`): schedule length is the proxy total.
4. Stable `wrela dump --stage=cost` with Terms (rule counts) + schedule
   totals + owner buckets.
5. **Short proxy summary in the image report by default**.
6. Off/on **proxy** A/B (rank order only; no wall-time oracles).
7. Capstone smoke: proven constant-index bounds elision for `[T; N]`
   literal indices.
8. Flip `compiler.costs.predicted-vs-measured` on dump/report + proxy A/B
   + semantic exact-matches — **not** predicted-vs-physical.

**One question:**

> Given two semantically equivalent emissions, which ranks lower under
> `wrela-cost-v1`?

**Doctrine:** differential direction is the product. Absolute cycles on
Apple vs Pi may differ (cache, etc.); rank for “fewer/cheaper ops, shorter
true deps” must not require those. Hosts do not calibrate the table.

## Vocabulary (settled — do not blur)

| Term | Means |
| --- | --- |
| **Proxy-cycle** | Unit defined by `wrela-cost-v1` **scheduler**; ranking metric, not host ns. |
| **ISA stream** | Final AArch64 words the sealed image runs (ARMv8.2-A + NEON baseline). |
| **Final stream** | `CodegenProgram` after the `--stage=asm` closure pipeline (runtime included). Not `.img` hex. |
| **CostRule** | Closed ISA op-class at `push` time; table keys match. |
| **Scoreboard** | Linear pass: `ready[reg]`, issue constraint, latency(rule); fn total = retire time of last insn. |
| **Rank / direction** | A < B under the proxy; must not depend on cache size or which conforming host runs it. |
| **Owner bucket** | `app` / `runtime` / `driver`. |
| **Proxy A/B** | Lower both; compare schedule totals — never wall time. |
| **Physical disposal** | Cleverness budget / M19 when a spend *lands*. |
| **Report summary** | Version + digest + schedule totals by owner; not Terms. |

### Item E — Scoreboard scorer + cost dump

**Files:** `crates/wrela-compiler/src/cost/score.rs`, `dump.rs`; wire
`cost::dump`.

**Algorithm (freeze 1311) — dumb, deterministic:**

```text
ready[reg] = 0 for all
cycle = 0
inflight_issue slots per the optional issue_width
for each EmittedWord in order:
  start = max(ready[s] for s in srcs, next_issue_slot_time)
  start = max(start, …)  # trivial port-free model
  finish = start + latency[rule]
  if dst: ready[dst] = finish
  record issue
fn_total = max retire time over words
```

No cache. No branch mispredict. No A76 ports. Fn proxy-cycles =
`fn_total`. Program total = sum of fn totals **or** documented
composition rule (prefer **sum of per-fn schedule lengths** for
compositionality; state it in the dump header).

**Dump format:**

```text
Cost version=1 digest=<hex> issue_width=<n>
  Assumptions ignore_cache=1 ignore_mispredict=1 target=isa_baseline
  Total proxy_cycles=<u64>
  Owner name=app proxy_cycles=<u64>
  …
  Fn key=<fn> owner=<bucket> proxy_cycles=<u64>
    Term rule=<id> count=<n>
    …
```

Terms = counts (review surface). `proxy_cycles` on Fn/Total = **schedule**.

- [ ] `score_program(program, table) -> CostReport`.
- [ ] Missing latency key → `Err`.
- [ ] Unit: dependent `add` chain longer than independent pair; eliding
  a load-use (hand-built words) shrinks total.
- [ ] Wire CLI.

**Cheap:** unit + dump stdout (pin in F).
